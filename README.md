# The Poem About Two Agents Agreeing

A short poem about agency — the power to choose and to act — about two agents agreeing on one plan.

## The poem

> Two hands on one rope, we chose the same pull.
> Not mine, not yours — the knot we both tied.
> Each of us gave up a little of the steering
> so the lantern we carry lights one road, not two.

## How to run

```sh
node main.ts
```

This writes the poem to `/output/entry.txt` (creating `/output` if needed). The output is deterministic — the same poem on every run.
